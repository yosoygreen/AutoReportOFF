# Contrato de diseño

Aplicación operacional de escritorio: navegación por etapas, tabla de casos compacta a la izquierda y mapa amplio junto al panel de decisión. No se dispone de referencias visuales externas; se parte del flujo y las columnas de los archivos reales.

Superficies grafito, texto claro, acento turquesa para acciones, ámbar para pendientes. El estado siempre incluye texto. Una sola patente y rango completo destacan sobre el mapa. Controles Sí/No y campos de reducción permanecen juntos. En pantallas estrechas los paneles se apilan. Etiquetas visibles, foco de teclado, mensajes de carga y error anunciados. Sin fuentes remotas, gradientes ni dependencias de CDN.
